# Model resources / 模型资源

Model binaries are downloaded by `Setup.cmd`, not committed to GitHub. This keeps a clean clone small and preserves each upstream's distribution channel. Source code, pinned URLs, checksums, configuration and attribution are included.

模型权重由 `Setup.cmd` 下载，不提交到 GitHub。完整工程包含源码、下载脚本、固定来源、校验、配置与许可说明；运行时依赖与模型不等同于工程源码。

`scripts/resources.py` prepares MDX/Demucs and FFmpeg; `scripts/game_resources.py` prepares GAME; `scripts/texture_resources.py` prepares the AccoMontage checkpoint and compact donor bank. `game-manifest.json` records the reviewed GAME signature. Other manifests record source URLs and SHA-256 hashes. Existing valid resources are reused.

See [THIRD_PARTY.md](../THIRD_PARTY.md) for source/license scope. Do not infer that a source-code license also licenses every upstream training recording. Files selected or generated by users are not part of the repository.
