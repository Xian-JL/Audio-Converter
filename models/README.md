# Model resources / 模型资源

Model binaries are downloaded by `Setup.cmd`, not committed to GitHub. This keeps a clean clone small and preserves each upstream's distribution channel. Source code, pinned URLs, checksums, configuration and attribution are included.

模型权重由 `Setup.cmd` 下载，不提交到 GitHub。完整工程包含源码、下载脚本、固定来源、校验、配置与许可说明；运行时依赖与模型不等同于工程源码。

`scripts/resources.py` prepares MDX/Demucs and FFmpeg; `scripts/game_resources.py` prepares GAME. The current instrumental setup uses `scripts/download_emotion_models.ps1` and `scripts/prepare_emotion_models.py` for EMO and MIDI Emotion. `emotion-models-manifest.json` records the selected files and local SHA-256 values; the official dictionaries are shipped as plain JSON under `server/data`. Existing verified weights and original archives are retained and reused.

AMT (`scripts/amt_resources.py`) and AccoMontage (`scripts/texture_resources.py`) are historical resources. They are not required for the default EMO generation route; keep installed copies when retaining historical experiments. Saved candidates reopen without loading inference weights. Models, archives, environments and binaries remain local; no training dataset download is required.

See [THIRD_PARTY.md](../THIRD_PARTY.md) for source/license scope. Do not infer that a source-code license also licenses every upstream training recording. Files selected or generated by users are not part of the repository.
